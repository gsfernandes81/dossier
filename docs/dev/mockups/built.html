Find at 47×45

Every screen at the size the phone actually reports — forty-seven columns, forty-five rows with the keyboard down and twenty-four with it up. No action bar: the terminal's own key row carries the verbs, and the only thing the app adds for a thumb is the count that reports what is expiring.

Browsing

Cold start. Two rows a document: name and expiry, then where the paper lives. The whole store, top to bottom, without typing anything.

Typing

Any letter is search text — there is nothing to press first. Raising the keyboard resizes the terminal rather than covering it, so the list keeps ten rows while you narrow it.

A record, and leaving

What a thumb can touch

Four regions, and only two of them are controls. Everything else the phone already provides.

tap the count — filter to what is expiring tap a row — select it tap it again — open the file tap the field — raise the keyboard

Dragging scrolls the list. Nothing else on the screen responds to a touch, and nothing that does is destructive.

All three are terminal attributes, not colours, so the screen reads the same in a monochrome theme, under NO_COLOR, and in whatever palette your terminal already uses.

CTRL and ALT latch: tap one, then tap the key it applies to. A long press holds them instead. Put this in ~/.termux/termux.properties and reload with termux-reload-settings:

extra-keys = [[ \
  {key: CTRL, popup: ESC}, {key: ALT, popup: TAB}, {key: SPACE}, \
  {key: LEFT, popup: HOME, display: "◀"}, {key: UP, popup: PGUP, display: "▲"}, \
  {key: DOWN, popup: PGDN, display: "▼"}, {key: RIGHT, popup: END, display: "▶"}, \
  {key: KEYBOARD, popup: ENTER} \
]]

ESC, CTRL and the four arrows are the minimum; the rest is comfort.
