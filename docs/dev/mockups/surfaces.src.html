Behind the Colon

Everything that is not finding a document lives behind a : command, pushed onto a back-stack that Esc pops. That is what keeps the base list letter-free — and it is what makes the whole app reachable from a phone keyboard that has no function keys.

Reached by :review · :file · :bundles · :expiring · :settings · ? Hotkeys ctrl+x expiring · ctrl+q quit Stack Esc pops exactly one layer

The command line U4

: switches the bottom bar from search to commands, in place — no modal palette floating over the screen. Prefix-matched with completion, so :re is enough. Every letter verb in the app has a command equivalent, which is the rule that makes a function-key-less phone a first-class citizen rather than a degraded one.

§3

The expiry watch is a filter, not a surface. v2 had a whole mode for it; the count in the header does that job now.

inv 4

One shared command catalog, and a check_action-style gate decides what is actionable right now — so the footer never advertises a verb that would fail.

Filing the backlog D11

612 files have been dropped and never filed. The desktop reads each scan with a vision model and proposes fields; the phone never runs a model, it just shows the proposal and takes a yes. Triage by exception — you see a card when the answer is ambiguous, not for every file.

D8

No model ever runs on the phone. The desktop reads scans and syncs the reading; the phone reads the answer. That constraint is permanent.

D11

Auto-filing high-confidence proposals is deferred — desktop-only if ever, never on mobile. A wrong auto-file is worse than a backlog.

§3

h restores a dismissed orphan. Review state is per-key last-write-wins, so a restore is expressible — a monotone union could only ever add dismissals.

Bundles §3

A bundle is the set you gather for a joining, a visa interview, a revalidation. Enter scopes the Find list to it; readiness is a count, not a checklist — the templates and validity rules from v2 are dropped.

The router porcelain

ds status is the one place that tells you what needs you, git-status style — and every line names the verb that fixes it. It absorbs v2's doctor, reconcile, syncthing status and expiring.

R1

“Journal healthy” is a real check, not a reassurance: it counts malformed lines, orphaned ops and duplicate writer keys, and watches for a high-water mark that went backwards — the signature of a file reverted behind Syncthing's back.
