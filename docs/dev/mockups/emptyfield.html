The Empty Field

The ⌨ chip is gone — Termux has its own keyboard key, and SPC takes that corner. Which left nothing telling a first-time user that the bottom of the screen is where you type. The field says it itself now, in two dim phrases inside the underline: an invitation on the left, and on the right a sentence that finishes on the button.

Field 39 underlined columns Texture underline + dim, two independent attributes Cost zero rows, zero state

The pair

For more, hit ends exactly where the chip begins. There is no gap to close and no punctuation joining them: the prose runs out of columns at the button, so the reversed SPC reads as the last word of the sentence and as the thing you press. That is the part worth protecting if the copy ever changes — the phrase must end on a verb that takes an object, or the chip stops completing it.

Leave the field bare and put the invitation among the hints, where all the other teaching lives.

It costs a hint its place, it is a row away from the thing it describes, and it stays visible while you type — telling you to start typing while you are typing. The placeholder's whole virtue is that it knows when to leave.

It leaves the moment you type

Does the underline still look right?

This was the thing worth checking, and it is fine — but for a reason worth writing down.

ConcernOutcome
Dim text under an underline — do the two fight? No. They are independent SGR attributes on the same cell: the underline stays at full intensity while the glyphs above it dim. The line reads as one continuous field with quiet text in it, which is exactly what a placeholder is.
Does the underline still span the whole field? Yes — all thirty-nine columns, always. The placeholder changes what is drawn on the line, never how long it is, so the field's geometry is identical empty, half-typed and full. A field whose underline grew and shrank would be worse than no underline.
Can the mockups even draw it? Not until now — the markup does not nest, so "dim inside underlined" needed its own class. Worth noting because the constraint is the generator's, not the terminal's: in Ratatui this is one Style with two modifiers.

What I would build

A, permanently. type any part of a name, dim, inside the underline, whenever the query is empty. Not first-run-only: that needs stored state, a decay rule and a decision about what counts as a run, and it buys nothing — the placeholder is invisible whenever you are actually using the field.

It is also the only copy here that teaches something the interface cannot otherwise show. The underline already says typable; what it cannot say is that coc will find "Certificate of Competency".

Your call on the wording. The mechanism is settled; the sentence is not. type any part of a name is twenty-three columns and there is room for about thirty-five, so there is slack for something longer if it earns it.

Alternatives that fit: type part of a name or tag · type anything from the name · search names, tags and shelves — the last one promises more than R3 delivers, so it would have to wait for the field to actually search tags.
