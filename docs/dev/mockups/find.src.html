The Find Surface

The app is a finder that happens to have management surfaces behind it. This is the screen you see 95% of the time — cold start, type, open, done. Every pane below is rendered on a real character grid: the phone screens are genuinely 45 columns wide, padded with display widths, so nothing here cheats on alignment.

Layout single list, flat, drill-down stack Phone 45×28 portrait Termux Desktop 100×26 Measured 6.2 ms to first paint

Cold start U1 · U2

One full-width list, sorted in physical shelf order — location, then slot, then name. No group headers: where a thing lives is row data and a filter, never a pane of its own. The search bar sits at the bottom, where a thumb is.

U2

Rows go two-line below ~70 columns: name and status on top, dim location · slot · tags underneath. The phone never truncates a name into uselessness.

inv 1

No letter keys are bound here at all. Every letter belongs to the search box — that is what makes find-fast possible, and it is why the panels moved to commands.

§1

Status is colour plus a marker: ! expired, ~ expiring, blank when tracked, · when it never expires. Readable in monochrome, and on a phone font with no Nerd Font glyphs.

§1

The count reads fzf-style — 4/948 — so you always know whether you are looking at a filtered view.

The record U3 · inv 2

Enter opens the file. → opens the record. That pair is the whole navigation model, applied by row kind everywhere in the app — and Enter never mutates and never dies: on a document with no file it falls through to the record instead of erroring.

U3

Detail is a sticky toggle, not a mode — open it once and it follows the cursor until you close it.

U4

Because detail is not a search surface, it may bind letters: s supersede, b bundle, u undo. Each also has a : command.

§4

Exactly two layout states. Split-capable at ≥ 100 columns, single-pane below. The old three-tier collapse ladder is gone.

R4

Undo is append the inverse op — the journal is the history, with a durable 30-day horizon.

Full width §1

Above ~70 columns rows collapse to a single line: name left, then dim tags, right-aligned location and slot, and the expiry column last so the status markers form a straight edge you can scan down.
